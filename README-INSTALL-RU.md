# Установка Monomachine Web V5.3.2 на GitHub Pages и iPhone

## Самый простой вариант: новый репозиторий из одного файла

1. На GitHub создайте **public** репозиторий, например `monomachine-web`.
2. Загрузите в корень репозитория **`index.html`**, **`sw.js`** и **`update-v53.html`** из этой папки.
   Главный файл обязан называться именно `index.html`; остальные два нужны, чтобы старая PWA не застряла в кэше.
3. Откройте **Settings → Pages**.
4. В **Build and deployment** выберите **Deploy from a branch**, ветку **main** и папку **/(root)**, нажмите **Save**.
5. Подождите появления адреса вида `https://ВАШ-ЛОГИН.github.io/monomachine-web/`.
6. Откройте этот адрес **именно в Safari на iPhone/iPad**.
7. Нажмите **POWER**, затем **▶ PLAY**.
8. Для иконки приложения: **Поделиться → На экран «Домой»**.

## Если репозиторий со старой версией уже есть

Надёжнее заменить не только `index.html`, а весь набор файлов из `monomachine-web.zip`:
содержимое папки `monomachine` должно попасть в корень репозитория. Тогда обновятся также
`style.css`, папка `js`, иконки, manifest, `update-v53.html` и новый `sw.js` V5.3.2.

Если на iPhone уже видна старая пустая панель, после загрузки файлов откройте в Safari
тот же GitHub Pages адрес с хвостом **`/update-v53.html`** и нажмите
**СБРОСИТЬ СТАРЫЙ КЭШ И ОТКРЫТЬ V5.3.2**. Не полагайтесь на старую иконку «Домой»:
после успешного входа через Safari удалите старую иконку и добавьте приложение заново.

## Чего не делать

Не открывайте `index.html` из приложения **«Файлы»**, Telegram или Quick Look. Там iOS может
показать только статичный HTML без нормального JavaScript/Web Audio: панель видна, но ручки,
страницы, треки и звук не оживают. Рабочий вход — опубликованная HTTPS-ссылка в Safari.

## Если появилась диагностика запуска

Если в диагностике написано `js/state.js: failed to load`, на GitHub Pages отсутствует папка
`js` либо файлы `state.js`, `sysex.js`, `audio.js`, `ui.js` ошибочно лежат в корне репозитория.
Самый быстрый ремонт — заменить корневой `index.html` однофайловым `index.html` из этой папки:
ему папка `js` не нужна. Альтернатива — переместить четыре JS-файла в папку `js/`.

- **ПЕРЕЗАГРУЗИТЬ** — обычная повторная загрузка опубликованной страницы.
- **СБРОСИТЬ КЭШ PWA** — удаляет service worker и кэш приложения на этом устройстве.
- **FACTORY BOOT…** — дополнительно удаляет локальные паттерны/киты из localStorage; используйте последним.

Проверьте также, что в настройках Safari включён JavaScript и для этого сайта не мешает блокировщик контента.

## На ПК нет звука

Сначала нажмите **POWER** или **▶ PLAY** — браузер запрещает звук до жеста пользователя.
Если LCD покажет `AUDIO SUSPENDED — CLICK PLAY AGAIN`, кликните по панели/PLAY ещё раз и проверьте,
что вкладка не выключена (mute), сайту разрешён звук и выбрано рабочее устройство вывода.
Если не нажимается вообще ничего, откройте не карточку предпросмотра, а Live Preview/GitHub-ссылку
или скачанный HTML в обычной вкладке Chrome/Edge/Firefox.

## Проверка после установки

В Safari должны быть видны 8 ручек DATA ENTRY, 7 страниц SYNTHESIS…LFO 3, 6 треков и 16 тригов.
При включении **POWER** на LCD должно быть написано **SFX-60+ WEB OS V5.3.2**; после **▶ PLAY** запускается секвенсор.
Если вместо этого снова пустая чёрная панель и TEMPO 120.0 — вы всё ещё смотрите старую копию/предпросмотр, а не V5.3.2.

> Firmware Lab хранит и анализирует пользовательский OS-файл, но не исполняет оригинальную
> прошивку Elektron. В приложении нет прошивки, ROM и сэмплов Elektron.
